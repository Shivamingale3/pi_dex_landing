# PiDex Landing Page

Single-page HTML landing for [PiDex](https://github.com/Shivamingale3/pi_dex). Zero JavaScript, zero dependencies. Dark theme, inline SVG mascot and icons, CSS-only carousel.

## Deploy

### Vercel
```bash
vercel --prod
```

### Any static host
Drop `index.html` on any web server.

## Sections

- Hero with mascot SVG (owl guardian + Telegram bell)
- Badges (version, Go, license, arch)
- What PiDex Watches — 12 icon grid
- Telegram notification previews — 3-slide CSS carousel
- Features — 6 cards
- Quick Start terminal block
- Commands reference table
- Footer

| Token | Value |
