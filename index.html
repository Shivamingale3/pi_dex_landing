▸ Features

Single Go binary
Under 5 MB. No runtime, no Python, no Node.js. Ships as a statically-linked executable.
Self-updating
sudo pidex update — pulls the latest release from GitHub. One command, restarts itself.
Interactive setup wizard
sudo pidex setup walks you through credentials, toggles, thresholds, and intervals.
Pre-built binaries
amd64 and arm64 releases on every tag. The install script downloads them — no Go required.
Zero external dependencies
Talks to systemd journal, /proc, Docker socket, and Telegram API directly. No agents, no daemons, no SDKs.
Data stays on your server
All logs, thresholds, and event processing happen locally. Only the notification text leaves your machine.

▸ Quick Start

# Install PiDex
$ curl -sSL https://raw.githubusercontent.com/Shivamingale3/pi_dex/main/deploy/install.sh | sudo bash

# Configure your Telegram credentials
$ sudo pidex setup

# Start the daemon
$ sudo systemctl enable --now pidex

# (Optional) Get shutdown alerts too
$ sudo systemctl enable pidex-shutdown

▸ Commands

CommandWhat it does
pidex runStart the daemon (runs as pidex user via systemd)
pidex setupInteractive configuration wizard (9 settings)
pidex test <event>Send a test notification — ssh-login, ssh-fail, sudo-used, docker-down, reboot
pidex test <event> --dry-runPrint event without sending to Telegram
pidex updateCheck GitHub for the latest release and self-update
pidex uninstallRemove PiDex, systemd services, and config
pidex versionShow installed version
pidex helpShow usage
